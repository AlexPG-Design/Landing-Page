Política de Privacidad

Este sitio web respeta y protege la privacidad de los usuarios. No se recopilan datos personales sin el consentimiento explícito del visitante.

Si se habilitan formularios de contacto, los datos proporcionados serán utilizados únicamente para responder a las consultas enviadas. No se compartirán con terceros ni se emplearán con fines comerciales.

Este sitio puede utilizar cookies técnicas para mejorar la experiencia de navegación. No se utilizan cookies de seguimiento ni cookies de terceros con fines publicitarios.

El usuario puede configurar su navegador para rechazar las cookies, aunque esto podría afectar a algunas funcionalidades del sitio.

Este sitio está alojado en GitHub Pages, lo que implica que ciertos datos técnicos (como la dirección IP, el tipo de navegador o la fecha de acceso) pueden ser registrados automáticamente por el servidor con fines estadísticos y de seguridad.
